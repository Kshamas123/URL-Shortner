# 🔗 URL Shortener - Backend Challenge #2

This project is part of my **Backend Challenge Journey**, where I build small yet functional backend applications to strengthen my backend development skills.

---

## 🚀 Project Overview
The **URL Shortener** allows users to input a long URL and receive a shortened version that redirects to the original link.  
It’s built using the **MERN stack** (MongoDB, Express.js, React, Node.js).

---

## ⚙️ Tech Stack
- **Frontend:** React, Axios, CSS
- **Backend:** Node.js, Express.js, Mongoose
- **Database:** MongoDB
- **Environment Management:** dotenv

---

## 💡 Features
- Convert long URLs into short, unique links.
- Store original & shortened URLs in MongoDB.
- Redirect users from the short link to the long link.
- Prevents duplicate entries (checks existing URLs).
- Modern futuristic UI for link input.
- Validates the user URL using regex
